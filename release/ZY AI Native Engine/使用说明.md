## 包内容一览

| 目录 / 文件 | 说明 |
|---|---|
| `运行 ZY AI Native 原生引擎.bat` | 一键启动脚本（推荐入口） |
| `platform/` | 大服务平台（SaaS 控制台后端，API `:18000`） |
| `project-server/` | 项目服务器（AI 执行引擎，`:8090`） |
| `edge-client/` | 本地边缘客户端（可选） |

## ⚠️ 前置条件：必须连接到 PostgreSQL

本系统的大平台（`platform`）和项目服务器（`project-server`）**强制依赖 PostgreSQL 数据库**。代码中硬编码使用 PostgreSQL 驱动（`gorm.io/driver/postgres`），**没有 SQLite / MySQL 等其他数据库的回退**。

如果 PostgreSQL 未启动、未建库或连接参数错误，服务会在启动阶段直接失败退出，**无法运行**。

仅「边缘客户端」（`edge-client`）使用本地 SQLite 文件，无需单独部署数据库。

### 三端数据库对照

| 端 | 数据库 | 是否必须 | 库名 |
|---|---|---|---|
| 大平台 platform | PostgreSQL | ✅ 必须 | `ai_native_engine` |
| 项目服务器 project-server | PostgreSQL | ✅ 必须 | `project_server` |
| 边缘客户端 edge-client | SQLite（本地文件） | 自动创建 | — |

## 一、准备数据库

1. 安装并启动 PostgreSQL（默认端口 `5432`）。
2. 创建两个空数据库（首次启动服务会自动建表，但需先建空库）：
   ```sql
   CREATE DATABASE ai_native_engine;
   CREATE DATABASE project_server;
   ```
3. 确保账号密码可连接，并具备建表权限。

## 二、首次配置（必须做一次）

### 1. 生成 config.yaml

发布包只附带示例配置，两端各需复制一份为正式配置：

```
platform\configs\config-示例.yaml   →   platform\configs\config.yaml
project-server\configs\config-示例.yaml   →   project-server\configs\config.yaml
```

### 2. 替换占位符

在两份 `config.yaml` 中搜索 `CHANGE_ME` 并替换（启动脚本检测到占位符会告警）：

| 配置项 | 位置 | 说明 |
|---|---|---|
| `database.password` | 两端 | PostgreSQL 密码 |
| `jwt.secret` | platform | 登录令牌密钥，任意长随机字符串 |
| `llm.deepseek.api_key` | project-server | DeepSeek API Key（`sk-...`） |
| `llm.glm.api_key` | project-server | 智谱 GLM API Key（可选，路由备用） |
| `project_server_forward.hmac_secret` | platform | **与下一行必须是同一个字符串** |
| `platform.hmac_secret` | project-server | 平台 ↔ 项目服务器互信密钥 |

> 也可以不改文件，改用环境变量注入（生产推荐）：大平台前缀 `AE_`（如 `AE_DATABASE_PASSWORD`、`AE_JWT_SECRET`、`AE_LLM_DEEPSEEK_API_KEY`），项目服务器前缀 `PS_`（如 `PS_LLM_DEEPSEEK_API_KEY`）。

## 三、一键启动

双击运行：

```
运行 ZY AI Native 原生引擎.bat
```

脚本会依次启动三端，并自动打开浏览器：

- **前端页面**：http://localhost （80 端口，由大平台静态代理）
- **大平台 API**：http://localhost:18000
- **项目服务器**：http://localhost:8090

各服务在独立窗口运行，**关闭对应窗口即停止该服务**。

> 如 80 端口被占用或无权限，修改 `platform\configs\config.yaml` 的 `web_port` 为其他端口（如 8080），然后改用 `http://localhost:8080` 访问。

## 四、首次使用向导

1. 打开 http://localhost ，**注册账号**并登录。
2. **创建公司**（数据面板 → 公司管理 → 创建公司）。
3. **创建项目**：左侧「项目管理」→ 新建项目向导，按提示填写基本信息与预算。
4. 实例地址填本机项目服务器：IP `127.0.0.1`、端口 `8090`（单机部署形态）。
5. 进入项目 → 确认执行策略 → 启动自动运营。

更详细的界面操作见 `manuals\新手入门到精通\`（20 章，从创建公司到经营指标全覆盖）。

## 五、LLM Key 与执行引擎配置

### 1. 千手 loop 引擎（执行真实任务）

编辑 `运行 ZY AI Native 原生引擎.bat`，找到：

```
set "QS_AUTH_TOKEN=deepseekkey 填写这里"
```

替换为你的 DeepSeek Key：

```
set "QS_AUTH_TOKEN=sk-...你的key"
```

千手 CLI 默认走 DeepSeek Anthropic 兼容端点，模型 `deepseek-v4-flash[1m]`，一般无需改动。如未安装千手，在 PowerShell 执行：

```powershell
winget install --exact --source winget --id Git.Git
winget install --exact --source winget --id OpenJS.NodeJS
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
# 关闭终端后重新打开，再执行：
npm install -g qianshou --registry=https://registry.npmmirror.com
```

### 2. 模型路由网关（AI 对话 / 拆解 / 验收等）

在 `project-server\configs\config.yaml` 的 `llm:` 段填入 `deepseek.api_key`（必填）与 `glm.api_key`（可选）。

### 3. 可选增强 Key

| 功能 | 配置位置 | 环境变量 |
|---|---|---|
| 知识库向量化（embedding） | `knowledge.embedding` | `PS_KNOWLEDGE_EMBEDDING_API_KEY` |
| 联网搜索 | `web_search` 段 | `PS_WEB_SEARCH_METASO_API_KEY` |
| 媒体生成（图像 / 视频） | `media` 段 | `PS_MEDIA_ARK_API_KEY` |

不配不影响主流程，对应功能会提示未开通。

## 六、可选配置

### 腾讯云 CVM 自动开通（远程实例部署）

需要平台自动创建云服务器时，在启动 bat 中填写 `AE_TENCENT_CLOUD_SECRET_ID` / `AE_TENCENT_CLOUD_SECRET_KEY` 及区域 / VPC / 子网等变量。**本地单机测试无需配置**（实例直接用本机 `127.0.0.1:8090`）。

### 边缘客户端（可选）

首次运行先在 `edge-client` 目录执行 `edge-client.exe -init` 生成配置（或参照 `configs\config-示例.toml` 修改为 `config.toml`），随后在启动脚本的询问时选择启动即可。用于本地文档扫描上传、会议资料导入。

## 七、启动前检查清单

- [ ] PostgreSQL 已启动，`5432` 端口可连接
- [ ] 已创建 `ai_native_engine` 与 `project_server` 两个空库
- [ ] 两端 `config.yaml` 已生成，`CHANGE_ME` 占位符已全部替换
- [ ] 两端 `hmac_secret` 为同一字符串
- [ ] 大平台 `jwt.secret` 已配置
- [ ] bat 中 `QS_AUTH_TOKEN` 已替换为 DeepSeek Key
- [ ] （loop 引擎需要）qianshou CLI 已安装

## 八、常见问题

| 现象 | 处理 |
|---|---|
| 启动即退出，日志报数据库连接失败 | 检查 PostgreSQL 是否启动、账号密码、两个库是否已建 |
| 启动时提示配置含 `CHANGE_ME` | 按「二、首次配置」替换占位符后再启动 |
| 平台无法连接项目服务器 | 确认 8090 端口服务窗口在线；两端 `hmac_secret` 是否一致；改动后需**重启 project-server** |
| 浏览器打不开 http://localhost | 80 端口被占用/无权限，改 `web_port`（见第三节说明） |
| 任务执行失败 / AI 无响应 | 检查 DeepSeek Key（`QS_AUTH_TOKEN` 与 `llm.deepseek.api_key`）是否有效、账户余额 |
| 前端页面已打开但接口报错 | 确认大平台 18000 窗口在线；刷新页面重新登录 |

更多排查手段见 `manuals\新手入门到精通\19-故障排查与红线.html`。

## 九、授权说明（机器码激活）

大平台启动时会自动联网激活：

- 未激活时仅能运行 **20~30 分钟**，到期自动关闭。
- 登录后在「设置 → 授权管理」页可查看**机器码、有效期**，输入授权码手动激活。
- 断网时若有历史激活记录，可离线宽限运行（最长不超过 1 年，1 年内至少联网激活一次）。
- 授权密钥通过环境变量 `AE_LICENSE_AUTH_KEY` 注入。
