# 大平台服务使用手册 · 平台用户（企业主 / 公司管理员）

> 适用角色：注册用户、公司管理员、项目负责人
> 后端前缀：`/api/v1`（JWT 鉴权）

## 一、账号与组织

- 注册 / 登录 / 刷新：`POST /api/v1/auth/register`、`POST /api/v1/auth/login`、`POST /api/v1/auth/refresh`。
- 公司管理：`POST /api/v1/companies` 建公司；`GET/PUT/DELETE` 查改删；`POST /:id/transfer` 所有权转移。
- 部门：`POST/GET/PUT/DELETE /api/v1/companies/:id/departments`。
- 成员：`GET/PUT/DELETE /api/v1/companies/:id/members`。
- 邀请：`POST/GET /api/v1/companies/:id/invitations`，接受邀请 `POST /api/v1/invitations/accept`。

## 二、项目管理

| 端点 | 说明 |
|---|---|
| `POST /api/v1/companies/:id/projects` | 创建项目（含基本信息 + 预算 + 可选云服务开通） |
| `GET /api/v1/companies/:id/projects` | 项目列表 |
| `GET/PUT/DELETE /api/v1/projects/:projectId` | 项目详情 / 更新 / 删除 |
| `PUT /api/v1/projects/:projectId/budget` | 更新预算 |
| `POST /api/v1/projects/:projectId/provision` | 手动录入服务器 IP（manual 模式） |
| `POST /api/v1/projects/:projectId/provision-cvm` | 云厂商自动开通（腾讯云/Linode） |
| `POST /api/v1/projects/:projectId/confirm` | 确认部署完成 |
| `POST /api/v1/projects/:projectId/status` | 状态流转（start/pause/resume/stop/complete） |
| `GET /api/v1/projects/:projectId/deploy-script` | 获取一键部署脚本 |
| `GET /api/v1/projects/:projectId/logs` | 开通日志 |
| 实例：`POST .../instance/restart|stop|start|terminate` | 实例重启/停止/启动/销毁 |

> **部署与开通要点（本批收紧）**：
> - 一键部署脚本的代码仓库地址为**必填配置**（`AE_DEPLOY_REPO_URL` / `AE_DEPLOY_REPO_BRANCH`）；未配置时云厂商自动开通会**显式报错**（fail-closed），不再拿占位地址静默执行；脚本已补 `nohup` 后台启动。
> - 健康检查端口与部署脚本 `server.port`、平台转发端口统一为同一配置来源。
> - 开通编排发生 panic 时会**回滚已创建资源**并把实例置为 `failed`；`confirm`（确认部署）与 `status(start)` 都会先校验实例存在。

## 三、平台账本与计费（真实资金账户）

| 端点 | 说明 |
|---|---|
| `GET /api/v1/ledger/balance` | 查询余额 |
| `PUT /api/v1/ledger/balance/threshold` | 设置预警阈值 |
| `POST /api/v1/ledger/recharge` | 充值 |
| `POST /api/v1/ledger/consume` | 记录消费（server/token/image/video/other） |
| `GET /api/v1/ledger/transactions?type=&category=&start=&end=` | 流水（按分类统计） |
| `GET /api/v1/ledger/alert` | 检查余额是否低于阈值 |

> token 计费由 project-server 自动 HMAC 上报到平台结算（`/api/v1/billing/report`），用户无需手动操作，可在 `/ledger/transactions?category=token` 查看 AI 算力费流水。平台按 `report_id` 幂等去重，**不会重复扣费**；若项目侧**未配置上报地址则上报不启用**，此时平台账本不含 AI 算力费（平台账本页已加说明）。

## 四、AI 对话

- `POST /api/v1/chat/conversations` 建对话；`GET` 列表；`GET/PUT/DELETE /:id` 详情/更新/删除。
- `GET /:id/messages` 历史；`POST /:id/stream` 流式对话；`POST /:id/tools/execute` 执行工具；`POST /upload` 上传附件。

## 五、项目服务器能力透传

以下项目服务器能力经平台 HMAC 签名代为转发，前端统一走 `/api/v1/...`（平台自动转发到 project-server）：

- `kb`（知识库）、`guided`（引导）、`agent` / `agent-org` / `agents` / `agent-configs` / `agent-runs`（智能体）、`connectors`（连接器）、`flow`（流程）、`events`、`strategy`、`deploy`、`marketing`、`backup`、`resource`、`reports`、`trust`、`arbitrator`、`templates`（19 组）
- `autoops`（自动运营）：`/api/v1/projects/:projectId/autoops/*`（71 端点透传）
- `optimization` / `notifications` / `features`

> **功能开关门控（本批已生效）**：`deploy` / `report` / `auto_report` / `marketing` / `strategy` / `trust_model` 六个开关**现在真的生效**——关闭状态下访问对应端点返回 **403** 与中文提示（不再 404 或静默通过）；未初始化 / 历史项目保持原样可用。功能分组与显示名以后端字典为唯一来源，未知 key 归入「其它」（不再回退英文 key）；「安全底线」类开关**后端强制不可关闭**。界面上 `report` 显示为「自动报告（复盘报告）」类、`auto_report` 显示为「智能报告」，两者可区分。
>
> ⚠️ `notification` 开关**仍未门控**（对应端点按 `user_id` 作用域，没有 `project_id`，需先改数据契约）。

## 六、常见问题

- 创建项目后 status=draft：manual 模式需先 `provision` 录入服务器，或创建时指定云厂商自动开通。
- 余额不足：token 计费上报会返回 2008 并停止扣费，需充值后由 project-server 重新上报。
