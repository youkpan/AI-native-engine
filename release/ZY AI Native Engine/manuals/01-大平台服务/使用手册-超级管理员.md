# 大平台服务使用手册 · 超级管理员

> 适用角色：平台超管（`is_super_admin=true`）
> 后端前缀：`/api/v1/admin`（JWT + SuperAdmin 鉴权）

## 一、全局看板

- `GET /api/v1/admin/dashboard`
- 返回：用户/公司/项目/实例总量、健康/异常实例数、累计充值/消费、Token 总量、Agent 成功率、预算消耗速率、在线 WS 客户端等。
- 健康实例口径：最近 5 分钟内有 `status=healthy` 心跳的实例（心跳由 project-server 经 HMAC 上报）。

## 二、用户 / 公司 / 项目穿透查看

| 端点 | 说明 |
|---|---|
| `GET /admin/users?keyword=&status=&page=&per_page=` | 用户列表（含公司数/项目数/消费/余额） |
| `GET /admin/users/:id` | 用户详情（公司、项目、余额） |
| `POST /admin/users/:id/ban` / `unban` / `reset-password` | 封禁 / 解封 / 重置密码 |
| `GET /admin/companies?keyword=&status=` | 公司列表 |
| `GET /admin/projects?keyword=&status=&mode=` | 项目列表 |
| `GET /admin/projects/:id` | 项目详情（预算、实例、最新心跳、近 30 天 Prompt 数） |

## 三、实例监控

- `GET /admin/instances?status=&page=&per_page=`：全部实例 + 最新心跳 + 项目名；实例**状态列已中文化**展示。
- `POST /admin/instances/heartbeat`：人工/运维手动上报心跳（保留兼容）。**机器（project-server）心跳应走 `/api/v1/heartbeat`（HMAC），不要走本端点。**

## 四、Token 消耗统计

- `GET /admin/tokens/overview?start=&end=`：Token 总量 + token 类消费金额。
- `GET /admin/tokens/stats?dim=user|project|model&start=&end=&limit=`：按维度统计。

## 五、Prompt 审计

- `GET /admin/prompts?keyword=&user_id=&project_id=&model=&start=&end=`：审计日志列表。
- `POST /admin/prompts`：追加审计日志（append-only，无修改/删除接口）。
- **导出**：范围为**当前筛选条件下的全部记录**（此前只导当前页）；内容中的手机号 / 邮箱与屏幕**同口径脱敏**，并对以 `= + - @` 开头的文本加前缀，防 CSV 公式注入。

## 六、治理审计汇总（V2.2 增强）

- `GET /admin/governance/audits?project_id=&report_type=&severity=&start=&end=&page=&per_page=`：治理报告列表，支持项目 / 类型 / 严重级别 / 时间范围过滤。
  - `report_type`：`internal_audit`（内审）/ `management_transcript`（管理转录）/ `risk_registry_snapshot`（风险登记册）/ `redteam_report`（红队）/ `change_log`（变更记录）
  - `severity`：`info` / `warn` / `critical`
  - `start` / `end`：RFC3339 时间（如 `2026-08-12T10:00:00+08:00`）
- `GET /admin/governance/audits/:id`：报告详情（含 findings/raw）。
- `GET /admin/governance/overview`：全局聚合视图（总量、severity 分布、critical 清单、类型分布）。

## 七、常见问题

- 治理列表想按时间筛：用 `start`/`end`（`reported_at` 区间）。
- 实例健康但看板异常：确认 project-server `callback_url` 指向 `/api/v1/heartbeat`，且实例 `hmac_secret` 已配置。
