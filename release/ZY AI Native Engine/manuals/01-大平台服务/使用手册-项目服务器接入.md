# 大平台服务使用手册 · 项目服务器接入（运维 / 开发）

> 适用角色：项目服务器（project-server）接入、运维工程师、后端研发
> 主题：机器对机器（HMAC）通信——心跳上报、token 计费上报、治理审计上报

## 一、HMAC 签名规范（两端统一）

请求头：

| 头 | 含义 |
|---|---|
| `X-Project-ID` | 平台侧项目唯一标识（`Project.ID`，uint 转字符串） |
| `X-Timestamp` | Unix 秒级时间戳 |
| `X-Signature` | `hex(HMAC-SHA256(timestamp + "\n" + body, secret))` |

- body 为空（GET/无 body）按 `timestamp + "\n" + ""` 计算。
- `multipart/form-data` 请求签名时 body 视为空串（边界符随机）。
- 密钥 = 平台为该实例签发的 `hmac_secret`（存于 `instances.hmac_secret_enc`）。
- 时间戳偏差 > `replay_window`（默认 5m）拒绝（2007）；验签失败统一返回 2006；精确重放（同 project_id+签名）拒绝（2007）。

## 二、三个机器上报端点（HMAC，不挂 JWT）

| 端点 | 说明 |
|---|---|
| `POST /api/v1/heartbeat` | 实例心跳上报（健康状态、任务队列、DB 状态、CPU/Mem/Disk） |
| `POST /api/v1/billing/report` | token 计费批次上报（幂等键 report_id） |
| `POST /api/v1/governance/report` | 治理审计汇总上报（内审/管理转录/风险登记册/红队/变更记录，幂等键 report_ref） |

> 旧路径 `/api/v1/projects/heartbeat` 已废弃，`/api/v1/admin/instances/heartbeat` 仅供人工运维（JWT+SuperAdmin），机器心跳务必走 `/api/v1/heartbeat`。

## 三、project-server 侧配置对齐

`configs/config.yaml` 的 platform 段：

```yaml
platform:
  callback_url: "https://<platform-domain>/api/v1/heartbeat"  # 必须新 HMAC 端点
  project_id: "{{PLATFORM_PROJECT_ID}}"                        # 平台 Project.ID
  hmac_secret: "{{HMAC_SECRET}}"                               # 与 instances.hmac_secret_enc 同源
  heartbeat_interval: 30s
  replay_window: 5m
```

## 四、心跳上报请求体（对齐 platform `HeartbeatRequest`）

```json
{
  "project_id": "42",
  "status": "ok",            // ok / degraded / down
  "timestamp": 1723410000000, // Unix 毫秒
  "version": "0.1.0",
  "uptime": "72h",
  "db_status": "ok",
  "ws_conns": 3,
  "pending_tasks": 1,
  "running_tasks": 2,
  "cpu_percent": 12.5,
  "mem_percent": 45.0,
  "disk_percent": 70.2
}
```

状态映射：`ok→healthy`、`degraded→degraded`、`down→down`；写入 `instance_heartbeats`，超管 dashboard 按最近 5 分钟 healthy 心跳判健康。

## 五、token 计费上报请求体

```json
{
  "report_id": "c9f6...-uuid",   // 幂等键，重复上报静默去重
  "report_from": "2026-08-12T00:00:00+08:00",
  "report_to": "2026-08-12T00:10:00+08:00",
  "input_tokens": 1520000,       // input = input_tokens + cache_creation
  "output_tokens": 480000,
  "cache_read_tokens": 3200000,
  "items": []                    // 明细可选
}
```

平台按单价（输入 1 元/M、输出 2 元/M、缓存读 0.02 元/M）重新核算 cost 并真实扣费；余额不足返回 2008（project-server 应保留本地流水，充值后换新 report_id 重报）。

## 六、治理审计上报请求体

```json
{
  "items": [
    {
      "report_ref": "audit-20260812-001",   // 幂等键（project_id + report_ref）
      "report_type": "internal_audit",
      "title": "8月12日连接器权限内审",
      "severity": "warn",                    // info/warn/critical
      "summary": "发现 2 项权限漂移",
      "findings": [{"level": "warn", "item": "connector: feishu notify", "action": "已自动降权"}],
      "raw": "{}",
      "reported_at": "2026-08-12T10:00:00+08:00"
    }
  ]
}
```

## 七、注意

- 实例级 HMAC 密钥 `instances.hmac_secret_enc` 以 **AES-GCM 密文**存储（历史 64-hex 明文由 `cmd/migrate-hmac` 一次性迁移为密文；新密钥签发即加密落库），不再明文存储。
- nonce 防重放为进程内缓存（单实例部署可接受）；多实例部署需换共享存储（Redis）。
