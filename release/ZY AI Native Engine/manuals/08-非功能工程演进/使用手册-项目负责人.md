# 使用手册：项目负责人（非功能工程演进相关）

## 1. 防烧钱与预算控制

- 项目预算唯一口径 = 总预算 + AI 运行预算（`ai_budget`）。
- 每轮开始前自动累计 token 计费消耗，≥ `ai_budget` 即暂停循环并通知；达预警线 `warn_line_pct`（默认 80%）通知。
- 单轮预算上限 `single_round_max_budget`（默认 100 元）已生效：轮末结算超限即告警并暂停项目。
- 补充预算后在项目设置调高 `ai_budget`，循环自动恢复。

## 2. 实例三要素（IP / 端口 / HMAC 密钥）

- 项目服务器实例的 IP、端口、HMAC secret 三者均可在项目配置界面管理：
  - 修改 IP/端口：`PUT /projects/:id/instance`
  - 查看/重设密钥：`GET/PUT /projects/:id/instance/secret`
- 本地多开调试：每个 project-server 进程配对应项目的 secret（`PS_PLATFORM_HMAC_SECRET`），监听不同端口（`project_server_port`）。

## 3. 无人值守安全边界

- 默认全自动执行；如需限制 AI 行为，在项目配置/提示词显式声明（连接器白名单、红通道禁止清单、人工红线）。
- 敏感写操作（对外发布/删除/付费调用）默认转人工处理节点，除非将 `autonomy_level` 设为 L0/L1。
- 现实世界线下动作（签约/物理操作/财务打款）无论自主级别一律转人工节点。

## 4. 人工节点超时自愈

- 人工节点含 `sla`（超时时长）与 `escalation_chain`（审核人→备选人→项目负责人→超管）。
- 超时策略二选一：升级链自动升级 / 超时降级（L2/L3→L1，AI 继续推进不等待）。
- 人工介入后可从原中断点恢复（`resume.go`，豁免期默认 2 天直接续接）。

## 5. 成员与 Agent 细粒度权限（14 项）

- 人+Agent 共有 11 项：read / write / run_task / spend_money / send_email / install_plugin / install_software / add_mcp / optimize_prompt / run_command / adjust_weight。
- 仅人类成员 3 项：pause_project / pause_task / user_manage。
- super_admin/admin 默认全量 14 项；member/ai_agent 默认 11 项。

## 6. 常见问题

| 现象 | 排查 |
|:---|:---|
| 功能开关 403 | 该开关处于**关闭**状态 —— `deploy` / `report` / `auto_report` / `marketing` / `strategy` / `trust_model` 六个开关现在真的生效（关闭即 403 + 中文提示）；到功能管理页开启即可。功能管理加载失败会显示失败态与重试；未选项目时会提示当前项目。「安全底线」类开关不可关闭 |
| 平台账本没有 AI 算力费 | 项目侧**未配置 token 计费上报地址**时上报不启用，平台账本自然不含该费用（平台账本页已有说明） |
| 项目账本无数据 | 确认已选项目（未选项目展示公司账本），账本经平台转发到 project-server |
| 人工节点卡死 | 检查节点 `sla`/`escalation_chain`，超时后走升级或降级 |
