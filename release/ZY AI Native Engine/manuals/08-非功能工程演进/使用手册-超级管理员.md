# 使用手册：超级管理员（非功能工程演进相关）

## 1. 全局可观测视图

- 实例状态表：后台「实例监控」展示各项目实例的 project_id / IP / 状态(ok/degraded/down) / 最近心跳时间 / 资源使用率 / 版本 / uptime。
  - 数据来源：project-server 心跳上报 `POST /api/v1/heartbeat`（HMAC 鉴权）。
- Token 消耗总盘：`/admin/tokens/overview` 按实例聚合 token 计费，含 qianshou 消耗。
- 项目执行进度：各项目 auto-ops 状态（running/paused/budget_exhausted/stopped）、任务完成数、最近轮次时间。
- 治理审计：`/admin/governance/overview` 全局治理聚合视图（审计报告/风险登记册/变更记录）。

## 2. 实例与密钥管理

- 实例 IP/端口可修改：`PUT /projects/:id/instance`（`project_server_port` 默认 8090，支持单机多开）。
- HMAC 密钥可查看/复制/重设：`GET/PUT /projects/:id/instance/secret`。
  - 重设后需将界面显示的 secret 同步到 project-server（`PS_PLATFORM_HMAC_SECRET` 环境变量或 config.yaml `platform.hmac_secret`），否则平台→PS 转发将 HMAC 401。
  - ⚠️ **轮换只告警、不自动下发**：轮换接口会返回 warning，需人工同步；在跑项目在同步完成前可能**短暂失联**（跨端自动同步尚未做）。

## 3. 告警与熔断监控

- 预算预警线默认 80%，由后端 `warn_line_pct` 统一驱动（与计费明细页同口径，不再硬编码 90%），达到即通知；达 100% 熔断暂停项目循环。
- 单轮预算上限 `single_round_max_budget`（默认 100 元）已生效：**轮末结算超限即告警并暂停项目**（金额维度熔断；时间维度另有单轮超时强杀）。
- Kill-Switch 分级急停：`POST /api/v1/projects/:id/autoops/killswitch`（scope=all/category/tool），每次触发写 change_logs 审计。

## 4. 安全与合规

- 审计链：`change_logs` / `audit_reports` / `risk_registry` 为追加式表，重大变更（任务删除、预算调整、RunConfig 修改、Kill-Switch）一律留痕。
- 凭据：第三方 API Key 使用 AES-GCM 加密存储，绝不落库明文；HMAC 密钥当前 MVP 明文存储（后续接入加密）。

## 5. 常见问题

| 现象 | 排查 |
|:---|:---|
| autoops 接口 403 | 平台 instance 表未录入正确 IP/端口/secret，或 project-server 未配 `PS_PLATFORM_HMAC_SECRET` |
| 实例心跳 down | project-server 停止超过 3 个心跳周期，或回调 URL 配置错误 |
| 预算熔断不恢复 | 补充 `ai_budget` 后重启/恢复项目循环 |
