# 使用手册 — 项目负责人（Owner）· 项目服务器执行引擎

## 1. 我能做什么

负责人是项目的最终决策者，掌控「引导建项 → 任务执行 → 流程审批 → 账本核算 → 经营看板」全链路。执行引擎在后台自动运行，你在关键节点保留控制权（审批、暂停、注入、预算）。

## 2. 核心操作

| 操作 | 入口/接口 | 说明 |
|---|---|---|
| 引导式建项 | 项目 → 引导对话 | 与 AI 对话逐步定义项目（核心问题/目标用户/资源/约束/里程碑），AI 先做网络研究再逐项提问 |
| 上传知识库 | 项目 → 知识库 → 新建知识库 → 上传文档 | 分「公司级共享」与「项目级」，检索时项目级优先（70%）；上传**扩展名白名单** `pdf / txt / md / markdown / docx / xlsx`（`docx`/`xlsx` 还需通过 OOXML 魔数校验，伪装/损坏文件返回 400），`pptx` 仍不支持；文档归属以 `kb_id` 查出的知识库为权威（自报不一致返回 403）；列表操作列有**文档级删除**入口（二次确认） |
| 创建/拆解任务 | 项目 → 自动运营 → 任务管理 → 新建任务 | 任务类型有「通用任务 general / 新建软件工程 eng / 软件修改 mod」；后两类会先进入规划（向导产出 PRD/TAD 后创建任务），可绑定知识库（kb_ids）；新建软件工程任务可填「**软件名称**」（留空 = 系统自动命名），工作区与文档路径按软件名隔离为 `{base}/project/{projectID}/{softwareName}/`（PRD.md / TAD.md / TAD/*.md / dev-plan.md），升级前落盘的旧路径首次读取会自动回退，老项目不受影响 |
| 暂停/恢复/编辑 | 任务管理 → 暂停 / 恢复 / 编辑 | 随时中断任务；补充新需求走**编辑任务描述 / 任务级提示词**（界面没有独立的「注入」按钮）；规划中的任务显示「继续规划 / 继续修改」 |
| 审批通过/拒绝 | 人工处理节点 / 验收记录（验收结论：通过 / 返工 / 驳回） | 对需要审批的任务人工判定；移动端可从通知链接进入审批页 |
| 流程审批 | 流程 → 审批请求 / 合规拦截 | 合规拦截（对外发布/删除/付费等）需人工放行 |
| 线下任务 | 流程 → 线下任务 | 推送飞书卡片，成员在线下完成后回报，回复回填 |
| 记账 | 账本 → 添加流水 | 记录收入/支出（第三方、采购、营销等科目） |
| 设置预算 | 账本 → 预算 | 设置总预算与预警线，耗尽自动暂停 |
| 智能看板 | 账本 → 看板卡片 / AI 生成 | 默认图表或 AI 生成 SQL/HTML 可视化（只读执行） |

## 3. 人在回路关键节点（须你关注）

- **合规拦截**：AI 发起「对外发布 / 删除 / 付费 / 打款」等敏感动作会被拦截，需你在「合规拦截」处放行或拒绝。
- **审批请求**：任务产物若需验收批准，会进入「审批」等待你确认。
- **预算预警**：预算接近预警线/耗尽时，系统通知并暂停，你补充预算后继续。
- **线下任务**：需要人工线下完成的节点（如提交资质、实地拜访）会推送飞书卡片，完成后回报。

## 4. 经营数据查看（阿米巴 / CRM / 驾驶舱）

> 说明：以下能力已在后端 Service 层实现（`internal/ledger/`），API 路由挂载后可在前端查看；当前版本以代码/单元测试为准。

| 模块 | 能力 | 说明 |
|---|---|---|
| 岗位级阿米巴 | 单位 token 附加值 / 三层钻取 / 内部计价 | 按角色归因 token 成本与产出价值，日结日清，项目→岗位→任务下钻 |
| 销售漏斗 CRM | 阶段流转 / 漏斗统计 / 角色转化率 | lead→opportunity→proposal→won/lost，转化归因到营销角色 |
| 经营驾驶舱 | 预算速率 / 任务积压 / token 异常 / 岗位 SLA 预警 | 异常触发 `cockpit_alerts` 并推送通知 |

## 5. 常见问题

- **支持哪些文档格式？** 上传扩展名白名单为 `pdf / txt / md / markdown / docx / xlsx`（`docx`/`xlsx` 需通过 OOXML 魔数校验）；`pptx` 仍不支持，其他后缀一律 400 拒绝。解析走降级路径（`docx`/`xlsx` 结构性降级、乱码占比 ≥5%）的产物**不再直接标「就绪」**，而是标为「**待人工确认（needs_review）**」并把原因写进错误信息。
- **想看阿米巴/CRM/驾驶舱页面**：后端 Service 已就绪，前端路由挂载后即可查看（待主对话在 `router.go` 注册）。
- **AI 任务卡住不动**：先**编辑任务描述 / 任务级提示词**纠偏（界面无独立「注入」按钮），再「暂停」排查，或走审批「拒绝」让 AI 返工。
- **反馈 / 案例晋级需要手填交互 ID 吗？** 不需要。提问的 SSE `done` 帧会下发 `interaction_id` + `session_id`，「采纳 / 拒绝 / 修改」与「提升为案例」直接挂在**回答卡片**上；页面左侧原两张表单保留为只读展示 + 复制按钮（兜底路径）。服务端**强制校验归属**（`session_id` 必填，不一致 403、记录不存在 404），填错只会失败，不会写到别人的交互记录上。注意：平台级 AI 对话仍**没有**反馈/评价入口。
- **预算不够了**：账本 → 预算 增加总额即可恢复运行。
