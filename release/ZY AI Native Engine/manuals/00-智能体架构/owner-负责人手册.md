# 使用手册 — 负责人（Owner）· 智能体组织

## 1. 我能做什么

负责人是每个智能体（Agent）的归属方，负责校准能力边界、维护工具知识、处理错误、判定任务达标。对应「负责人制」：**每个 Agent 必须有负责人**。

## 2. 核心操作

| 操作 | 入口/接口 | 说明 |
|---|---|---|
| 创建 Agent | 项目 → 组织与运营 → 智能体 →「组织」页签 → 新建 Agent | 必须填 `owner_id`（负责人），否则创建失败 |
| 设置岗位画像 | 新建 Agent 弹窗（角色描述 / 职责边界 / 人工红线） | 填写角色描述、职责边界、人工红线（不可跨越） |
| 绑定技能 | 成员列表 → 「技能」按钮 | 版本化绑定，**全量替换**：本次未勾选的旧技能会被覆盖，空数组则清空全部 |
| 岗位模板配连接器 | 智能体中心 →「组织」→ 岗位模板库 → 详情 / 新增模板 → 连接器 | 连接器在**岗位模板**上登记 |
| 授权 / 撤销连接器（Agent 级） | 接口 `POST|GET|DELETE /api/v1/agent-org/agents/:agent_id/connectors` | **当前界面暂无 Agent 级连接器区**；需**最小权限** `scope`（使用范围），否则拒绝授权 |
| 转移负责人 | 接口 `POST /api/v1/agent-org/agents/:agent_id/transfer` | **当前界面暂无「转移」按钮**；所有权可转移到新负责人 |
| 启停 Agent | 成员列表操作列「暂停 / 启用」 | active / paused / inactive |

**岗位治理要点（本批已落地）**：

- **上岗测试有真实判定**：按「角色在岗 / 有启用版本且提示词非空 / 期望技能已装配」三项判定，结论落库；**未通过会生成人工节点并停用该角色**（阻断调度），需处理后重新上岗。
- **阶段切换弹窗与实现一致**：已存在的岗位自动跳过、缺失技能跳过装配并给人工提醒、预算不足仅预警不阻断。
- **扩编（一键应用建议）加名称唯一约束**：并发 / 双击窗口不再产生同名重复角色，重复创建返回明确业务错误。
- **角色模板按 `category` 匹配**：同名的 `manager` 不再跨分类串模板。
- ⚠️ **技能白名单仍是建议性**：装配结果只进上下文，**尚未构成执行约束**（未强制拦截白名单外调用）。

## 3. 人工红线

- 每个 Agent 都必须设置 `human_red_line`，明确该 Agent 不可跨越的边界。
- 管理者（manager）Agent **只做管理不下场执行**；实际任务由员工（worker）Agent 执行。
- 连接器授权遵循最小权限，写操作默认需人工审核（`write_review`），切勿开启 `write_auto`（高危）。

## 4. 常见问题

- **创建 Agent 报错「owner_id is required」**：说明未指定负责人，补齐负责人即可。
- **授权连接器报错「scope is required」**：连接器授权必须填写使用范围，这是最小权限保护。
- **想换负责人**：使用「转移负责人」，不要删除重建（保留绩效与经验数据）。
- **技能勾了却没生效？** 技能白名单目前是**建议性**的（仅进上下文），不构成强制拦截，属已知现状。
