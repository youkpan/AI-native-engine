# 使用手册 — 超级管理员（Admin）· 智能体组织

## 1. 我能做什么

超管可跨公司/项目查看智能体组织全貌，用于平台级治理与合规检查。

## 2. 查看能力

| 操作 | 说明 |
|---|---|
| 查看组织树 | 查看某项目下管理者 → 员工的层级结构 |
| 查看 Agent 列表 | 支持按 `type`（manager/worker）过滤 |
| 查看连接器授权 | 查看某 Agent 已授权的连接器及其 `scope` 范围 |
| 查看绩效 | 查看 Agent 的质量分、返工率、TOP 返工原因 |

## 3. 合规关注点

- **负责人制**：核查是否每个 Agent 都有 `owner_id`，无负责人的 Agent 属治理缺失。
- **连接器最小权限**：核查连接器授权是否都填写了 `scope`，避免无范围的全量授权。
- **敏感字段脱敏**：连接器的 `Config`（含 API Key）在列表/详情接口中不输出（`json:"-"`），超管无法直接读到明文。
- **管理者不下场**：核查 `type=manager` 的 Agent 是否只做分配、未直接执行任务。

## 4. 常见问题

- **看不到连接器密钥**：属预期行为，敏感配置加密存储且不序列化输出，符合最小权限设计。
