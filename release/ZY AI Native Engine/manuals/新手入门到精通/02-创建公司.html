第 02 章 · 第一步：把公司开起来

第02章 注册与创建公司

从注册一个账号，到建好你的第一家「公司」，逐字段讲清：填了会有什么后果、以后还能不能改。

阅读约 14 分钟 新手友好 重点：每个字段的影响与可改性

这一章回答一个你最关心的问题：「我怎么创建公司？这些信息填了，对后面到底有没有影响？」答案一半是好消息——绝大多数字段以后都能改、代价极低；另一半是你必须提前知道的几个「不可撤销」动作（转让所有权、解散公司）。读完这一章，你就知道哪些可以随便填、哪些要慎重。

你将学会

  • 注册账号、登录，并理解登录后「回到原来想去的页面」这个行为
  • 创建第一家公司，看懂「公司名称 / 行业类型 / 描述」三项各自的作用
  • 用一张表看清每个字段「填什么好、影响什么、以后能改吗、改的代价」
  • 走通公司管理页的五个页签：列表、组织架构、成员、邀请、设置
  • 理解 14 项权限的人话含义，以及一人公司该怎么给自己和 AI 开权限

一、从注册到登录

登录页 › 还没有账号？立即注册

第一次打开平台，你会停在登录页。页面上是两个输入框和一个按钮：请输入邮箱、请输入密码、登录。底部有一行小字：还没有账号？立即注册。点它，进入注册页。

注册页的四个字段

注册页标题「创建账号」，需要填四项，全部必填：

字段提示文字（placeholder）校验规则（填错会提示）
用户名请输入用户名必填；长度 1–64（提示「用户名长度 1-64」）
邮箱请输入邮箱必填；需合法邮箱格式（提示「请输入正确的邮箱格式」）
密码请输入密码（至少 6 位）必填；长度 6–64（提示「密码长度 6-64 位」）
确认密码请再次输入密码必须与上面密码一致（提示「两次输入的密码不一致」）

填完点 注册。成功后页面提示 「注册成功，请登录」，并自动跳回登录页。注册页底部也有「已有账号？返回登录」。

邮箱是唯一身份，务必填真实的

邮箱就是你的登录账号，也是系统识别「你是谁」的凭据。用户名只是显示名（界面上的称呼），可以重复、可以后改；但邮箱在系统里是唯一的——注册时若提示「用户已存在」，说明这个邮箱已经注册过了，直接去登录即可。

登录：注意「登录后回到哪」这个行为

登录页校验是：邮箱填错格式会提示 「请输入正确的邮箱格式」；密码不足 6 位提示 「密码至少 6 位」。登录成功提示 「登录成功」。

一个容易被忽略但很贴心的细节：登录后会回到你原来想去的那个页面。比如你还没登录时直接打开了一个项目详情链接，系统会让你先登录，登录完自动跳回那个项目页，而不是总把你丢回数据面板。实现上，登录页会读 URL 里的 redirect 参数，并且只接受「站内路径」（以 / 开头、非 //），防止被引导跳去外部网站。

二、创建你的第一个公司

左侧菜单「公司管理」 › 右上角 创建公司

登录后进入平台，左侧菜单里找到 公司管理，点进去，右上角有一个 创建公司 按钮。点它，会弹出「创建公司」弹窗，里面有三个字段：

字段必填提示文字 / 交互长度限制
公司名称是请输入公司名称1–128 字符
行业类型否（可不选）下拉框，请选择行业，可搜索、可清空—
描述否简要描述公司（可选），多行文本框最多 512 字符

弹窗底部两个按钮：取消 和 创建。创建成功提示 「公司创建成功」。

三个字段里只有「公司名称」是必填

行业类型和描述都可以留空，等想清楚了再去「公司设置」里补。所以第一次用别卡在「行业到底选哪个」上——先建起来，后面随时能改。

行业类型的完整选项清单（抄自代码）

创建公司弹窗里的「行业类型」下拉框，可选值是写死在代码里的这 14 项（顺序不变）：

智能制造
互联网/IT
金融
教育
医疗健康
电商零售
物流运输
房地产
能源环保
文化传媒
咨询服务
农林牧渔
建筑工程
其他

它存在哪里、被谁读？这个「行业类型」写进公司的 industry 字段（数据库里最长 64 字符）。它会被读到的场景有：

  • 「我的公司」列表里的「行业」列展示；
  • 超管后台按公司名或行业做关键词搜索时；
  • 平台侧 AI 对话在需要「列出你的公司」时，能看到这个字段。

换句话说：公司这个「行业类型」目前只是展示与统计用途，不会注入到 AI 的执行逻辑里。真正影响 AI 行为的「行业」是项目里另一个独立的「行业」字段（自由文本，建项目时自己填），两者不是一回事，别搞混。

三、【重点】这些信息对后续有什么影响

这是全章最重要的一节。一句话结论先说：公司名称、行业类型、描述这三项，都只影响「展示与统计」，不影响 AI 怎么干活；真正需要慎重的是「所有者」和两个不可撤销操作（转让、解散）。下面是逐字段的完整结论。

字段填什么好影响什么以后能改吗改的代价
公司名称 真实、好认、能对客户亮出来的名字（个人可「XX 工作室」，团队用真名） 出现在「我的公司」列表、顶栏公司切换器、面包屑、公司账本等处；可能成为对外内容署名的一部分 能改（公司设置 → 保存修改） 极低。改完即时生效；若已在对外材料里署了名，需同步改外部，系统内无历史改名成本
行业类型 从 14 项里选最接近的一个；实在选不出就「其他」 主要影响展示与统计（列表展示、超管按行业搜索）。当前不注入 AI 执行逻辑，不影响模板推荐、提示词或 AI 策略 能改（公司设置里是自由文本框，可改成任意文字） 极低
描述 一句话说清公司定位（如「一人跨境电商独立站」） 存库并在「我的公司」列表展示；平台侧 AI 对话列公司时能看到它，不进入项目服务器的执行上下文或知识库 能改（公司设置 → 保存修改） 极低
所有者 创建公司的这个人，自动成为所有者 所有者是最高权限：只有所有者能解散公司、转让所有权、授予 super_admin。公司的项目、计费主体都挂在所有者名下 能改，但不可撤销（公司设置 → 转让所有权给另一位成员） 高。转让后你不再是最高权限，且此操作不可撤销，务必确认对方是可信的团队成员
两个「不可撤销」动作，做之前想清楚

① 转让所有权：确认文案是「确定要转让公司所有权吗？此操作不可撤销。」转出去就收不回来了。② 解散公司：说明文字是「解散后公司将无法恢复，所有数据将被软删除。仅所有者可操作。」这两个是本章唯一的「慎重点」。

✅ 这样填

第一次建公司：名称用真实的名字，行业先选一个最接近的，描述留空或一句话。建完先跑起来，等业务清晰了再回「公司设置」把描述补详细。

❌ 别这样做

在「行业到底选哪个」上纠结半天不敢点创建；或者随手把「所有者」的转让/解散当测试点着玩——这两项不可撤销，点错了真回不来。

四、公司管理页的五个页签

公司管理页顶部有五个页签：公司列表 / 组织架构 / 成员管理 / 成员邀请 / 公司设置。其中后四个页签需要先选一家公司才会激活（未选公司时它们是灰的）。下面逐个走一遍。

页签一：公司列表

标题是 「我的公司」，右上角 创建公司。表格列是 公司名称 / 行业 / 描述 / 状态 / 操作。状态有两种：正常 和 已停用。操作列有两个按钮：进入 和 设置。如果一家公司都没有，表格空态提示 「暂无公司，点击右上角创建」。

两个按钮的区别：点 「进入」 和点 「设置」 效果基本一致，都是把这家公司设为「当前公司」并跳到「公司设置」页签——因为后四个页签都围绕「当前选中的公司」工作。真正切换全局「当前公司」的地方，是顶栏的公司切换器（见本章第六节）。

页签二：组织架构（部门）

这个页签管理公司的部门树。左侧卡片标题「部门树」（空态「暂无部门」），右侧卡片标题会根据状态在 「编辑部门 / 新建部门 / 部门详情」 之间切换。右上角有 新增部门 按钮。

新建/编辑部门的表单有三个字段：部门名称（请输入部门名称）、上级部门（下拉树，无（顶级部门） 表示顶级部门）、排序（数字，控制同级部门的前后顺序）。按钮是 保存/创建 和 重置。

权限：只有公司所有者或管理员能调整组织架构。如果你不是管理员，右侧会显示提示 「仅公司所有者/管理员可调整组织架构」，只能看不能改。删除部门时会弹确认 「确定要删除部门「X」吗？」。

默认有一个「全体」部门，删不掉

创建公司时系统会自动建一个叫 「全体」 的顶级部门，作为兜底容器，且这个「全体」部门不允许删除（后端会拦）。所以再小的公司也至少有一个部门。

一人公司怎么建部门：先别建

一人公司没有「跨部门协作」的问题，绝大多数时候保留「全体」一个部门就够了，把成员（你自己 + 以后的 AI Agent）都挂在「全体」下即可。等真的招了第二个真人、需要「市场部 / 技术部」分权时，再回来加部门。部门是用来分权和归类的，不是用来凑热闹的——不要照搬大公司的组织树空转。

页签三：成员管理

这个页签列出公司所有成员。表格列：姓名 / 邮箱 / 员工ID / 角色 / 状态 / 加入时间 / 操作。角色有四种：超级管理员、管理员、普通成员、AI Agent。操作列是 编辑 和 移除。

点「编辑」打开「编辑成员」弹窗，字段有：成员（只读展示姓名和邮箱）、角色（下拉：超级管理员/管理员/普通成员/AI Agent）、部门（选择部门）、员工ID（员工工号（可选））、方向（所属方向/条线（可选））、负责人指派（三个复选：方向负责人 / 项目负责人 / 任务负责人）、权限（权限矩阵，见下一节）。

权限门控：不是所有成员你都能改。点「编辑」或「移除」时，如果对方层级不比你低，按钮会被禁用，并提示 「无权管理该成员：需公司所有者，或角色层级高于对方」。移除成员前会确认 「确定要移除成员「X」吗？」。

AI Agent 不可授予管理权限

在权限矩阵里，当角色选成「AI Agent」时，三项管理权限（暂停项目 / 暂停任务 / 用户管理）会被禁用，并显示提示 「AI Agent 不可授予管理权限」。这是硬规则：AI 永远不能拥有「暂停项目、暂停任务、管理用户」这三项人类专属的权力。

页签四：成员邀请

这个页签用来邀请真人或 AI Agent 加入公司。右上角 生成邀请。页面顶部有一条说明：「邀请码有效期为 7 天。将邀请码或链接分享给团队成员，他们注册/登录后通过「接受邀请」加入公司。」（如果你不是管理员，这里会变成一条「仅公司所有者/管理员可管理邀请」的提示）。

邀请列表列：邀请码 / 邮箱 / 角色 / 状态 / 过期时间。邮箱如果没指定，显示 「不限制」（谁拿到邀请码都能用）。状态三种：待接受 / 已接受 / 已过期。

点「生成邀请」打开弹窗，字段：邮箱（留空则不限邮箱（可选））、角色（管理员/普通成员/AI Agent，注意这里没有「超级管理员」——超级管理员只能由所有者在成员管理里授予）。弹窗底部按钮是 生成。生成成功提示 「邀请生成成功」；点邀请码旁的复制按钮会提示 「邀请码已复制」。

页签五：公司设置

这个页签分两块：左边是 「公司信息」，右边是 「转让与解散」 危险区。

公司信息卡片里是四个字段：公司名称（可改）、行业类型（这里变成自由文本框，可输入任意文字，最长 64 字符）、描述（多行，最长 512）、所有者 ID（只读，展示当前所有者的用户 ID）。改完点 保存修改，成功提示 「保存成功」。

转让与解散危险区有两件事：

  • 转让所有权：选 选择公司成员 作为「新所有者」，点 确认转让。确认弹窗是 「确定要转让公司所有权吗？此操作不可撤销。」转让后你不再是最高权限。
  • 解散公司：说明文字 「解散后公司将无法恢复，所有数据将被软删除。仅所有者可操作。」，按钮 解散公司，二次确认后执行。

五、成员与权限速查

在「成员管理 → 编辑成员」里，有一个权限矩阵，一共 14 项权限开关，分成两组：通用权限（人 + AI Agent 共有，11 项）和管理权限（仅人类成员可选，3 项）。下面是每一项的人话解释：

权限 key界面显示人话解释谁能有
read读能查看公司/项目里的数据人 + Agent
write写能新增、修改数据人 + Agent
run_task运行任务能触发、执行任务人 + Agent
spend_money花钱能产生花费（调用付费能力、消耗预算）人 + Agent
send_email外发邮件能对外发送邮件（连接器 send_email 工具）人 + Agent
install_plugin装插件能安装插件人 + Agent
install_software装软件能安装软件人 + Agent
add_mcp加 MCP能新增 MCP 连接器（AI 连外部系统的插头）人 + Agent
optimize_prompt优化提示词能优化提示词人 + Agent
run_command运行命令行能执行命令行指令人 + Agent
adjust_weight调权重能调整权重（如任务时间片权重、模型路由权重）人 + Agent
pause_project暂停项目能暂停整个项目仅人
pause_task暂停任务能暂停单个任务仅人
user_manage用户管理能管理用户/成员仅人

角色默认权限是这样分配的：超级管理员和管理员默认拥有全部 14 项；普通成员和 AI Agent 默认只有 11 项通用权限（不含三项管理权限）。这也解释了为什么 AI Agent 永远拿不到「暂停项目 / 暂停任务 / 用户管理」。

一人公司给自己开哪些：重点不是「开满」，是给 AI 留人工关卡

作为所有者，你天然是超级管理员（14 项全开），这是「人的权限」，没问题。真正的风险在给 AI Agent 开哪些：AI Agent 默认就带 11 项基础权限，其中 spend_money（花钱） 和 send_email（外发邮件） 这两项最值得警惕。建议：即便权限列表里 AI 有这两项，也把项目的运行模式留在「半自动」或「人工审核」——让真正花钱、真正对外发邮件的动作，在你点头之后才执行。不要图省事一开始就全自动 + 全权限，否则 AI 可能在你看不见的时候把预算花出去或把邮件发给客户。

六、多公司的用法

顶栏 › 公司切换器（placeholder「选择公司」，首项「全部公司」）

平台支持你同时拥有多家公司。顶栏的公司切换器就是一个下拉框，placeholder 是 「选择公司」，第一项固定是 「全部公司」，下面列出你加入的每一家公司。

选「全部公司」等于不指定公司（相当于清空当前公司）。选某一家公司，就把它设为「当前公司」，之后建项目、看知识库、进账本，都会落在这家公司下面。切换公司时，系统会顺手清掉之前残留的项目上下文，避免串台。

什么时候该建第二家公司

  • 不同业务主体：比如你既有一个跨境电商，又有一个咨询业务，两者不该混在一家公司里，分开建更清晰。
  • 隔离风险与账：两家公司各自独立账本、独立成员、独立项目，一条线出了问题不牵连另一条。
  • 分别核算：财务、战略上想分开算的两摊生意，就该是两家公司。

什么时候不该建

早期（尤其一人公司）别为了「看起来正规」就拆一堆公司。公司是组织容器，项目才是生意容器——同一家公司下可以挂多个项目。一开始专注把一条业务线跑通，比分散注意力经营好几家空壳公司有意义得多。等真出现第二个业务主体、或需要隔离风险时，再开第二家也不迟。

七、本章小结与下一步

  • 注册登录：邮箱是唯一身份，用户名只是显示名；登录后会回到你原来想去的页面。
  • 创建公司：三个字段里只有「公司名称」必填，行业和描述都能后补。
  • 字段影响：公司名称/行业/描述都只影响展示与统计，不影响 AI 执行逻辑；真正要慎重的是「所有者」和转让、解散两个不可撤销动作。
  • 行业类型：14 个下拉选项，目前不进 AI 执行逻辑；项目里另有一个独立的「行业」字段，那才可能影响营销/策略等 AI 功能。
  • 权限：14 项权限分「通用 11 项 + 管理 3 项」，AI Agent 拿不到管理权限；一人公司别给 AI 的「花钱」「外发邮件」留全自动。
  • 多公司：同一业务别拆一堆公司，真出现第二个业务主体再开。

公司建好了，下一步就是在它下面建第一个项目——那是真正让 AI 开始干活的地方。
