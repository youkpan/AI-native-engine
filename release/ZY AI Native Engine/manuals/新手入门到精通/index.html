二、十分钟快速上手

如果你现在只想"先跑起来看看到底是什么"，按这个顺序做，一圈下来大约十分钟：

  1. 注册并登录

    在登录页点 还没有账号？立即注册，填「用户名 / 邮箱 / 密码 / 确认密码」四项，注册后用邮箱登录。详见 第 02 章。

  2. 创建你的第一家公司

    左侧菜单 公司管理 → 右上角 创建公司，填「公司名称 / 行业类型 / 描述」。公司是你的"组织容器"，项目必须挂在公司下。

  3. 建第一个项目

    顶部把公司切换器选到刚建的公司，再进 项目管理 → 新建项目。向导只有三步：基本信息 → 预算设定 → 确认提交。

  4. 第一周把运行模式留在「半自动」

    半自动的意思不是"AI 少干活"，而是关键决策要你点头。第一周用它，你能看懂 AI 的行为逻辑，再决定要不要放开。

  5. 打开自动运营控制台，认识那 16 个入口

    任务管理、运行轮次、人工节点、经营日报…… 这 16 个按钮就是你和 AI 团队打交道的全部门面，见 第 06 章。

  6. 下第一个任务，等它跑完看验收结论

    自动运营 → 任务管理 → 新建任务。任务跑完后会有独立验收 Agent 给出「通过 / 返工 / 驳回」，不是你判断，也不是干活的 AI 自己判断。

四、先搞清楚三个概念，后面就不迷路

概念一：公司 → 项目 → 任务，是三层容器

公司是组织容器（放人、放钱、放共用知识）；项目是生意容器（一个项目 = 一条业务线，有独立服务器、独立预算、独立账本）；任务是干活单元（AI 团队按轮次推进的最小对象）。所有操作入口都长在这个三层结构上，迷路时就问自己"我现在在哪一层"。

概念二：AI 不是一个大模型，是一支有岗位的队伍

项目里干活的叫智能体（Agent），有管理者也有员工，各自带岗位职责、技能白名单和运行配置。你下达的任务会被这支队伍按"时间片 + 轮次"轮流推进，干完由另一个 Agent 独立验收。所以本书讲"怎么建智能体"和"怎么派任务"是两件不同的事。

概念三：两条账本，别搞混

公司账本是你真金白银的账户（充值、AI 算力费、云服务器费）；项目账本是这条业务线的经营核算（收入、支出、预算消耗）。AI 烧的是公司账本里的钱，花超了会按项目预算熔断——两个数字都要看，但看的位置不一样。
