一、平台侧页面全景：一张地图

先忘掉细节。任何一个平台侧页面，屏幕都被切成三块：上面一条顶栏，左边一条侧边栏，中间一大片内容区。你所有的操作都发生在这三块里。

顶栏折叠按钮、公司切换器、通知铃铛、主题切换、用户菜单
＋
侧边栏一级菜单（9 项常显 + 超管后台），进项目后多出 6 个分组
＋
内容区当前页面本体：标题、按钮、表格、弹窗

三块里只有中间那块会随页面切换而变。顶栏和侧边栏从你登录那一刻起就在，是你「不迷路」的两个锚点——不知道自己在哪时，先看侧边栏哪一项被高亮。

为什么侧边栏会「时多时少」

很多新手第一次遇到这种情况会慌：刚登录时侧边栏只有十来项，点进一个项目之后，突然从「项目管理」下面冒出来 6 个分组。这不是 bug，而是设计：

没进项目时（平台视角）

侧边栏只显示 9 个一级页面 + 超管后台。这时的你站在「公司」这一层，管的是组织、项目清单、账本、设置。

进了某个项目时（项目视角）

在「项目管理」和「知识库」之间会插入 6 个分组菜单（建项与定义、组织与运营、接入与执行、研究与获客、治理与资源、运维与报告），整条侧边栏一下子长出一大截。

判断「我现在在哪一层」有一个特别简单的办法：看侧边栏有没有那 6 个分组。有，说明你已经在某个项目里了，你接下来的操作只影响这一个项目；没有，说明你还在平台层。

进阶：这 6 个分组菜单，什么时候才会出现

它们出现的条件是当前网址里带着项目号——也就是形如 /project/123/... 这样的路径。你从「项目管理」点进一个具体项目时，网址就会带上这个项目号，侧边栏随之展开。返回平台层（比如点「数据面板」）后，网址里的项目号消失，那 6 个分组也就收起来了。

另外有一个细节：当你离开项目、回到平台层时，系统会顺手把「当前选中项目」清空，避免你在账本页看到的还是上一个项目的数据。所以从项目里退出来之后，账本等页面会自动切回公司视角，这是对的，不是丢数据。

铃铛上的未读数会自己刷新

未读条数不用你手动刷新，页面会每隔 30 秒自动去查一次。所以你在别的标签页里处理完一条通知，回到这个页面时角标很快就跟上了。

公司切换器：全平台最该先搞懂的一个控件

这个下拉框决定了「你现在以哪家公司的身份在操作」。它有三个状态，含义完全不同：

全部公司

下拉里的第一项，对应数值 0。选了它，数据面板显示的会是你能看到的所有公司汇总。

某一家具体公司

选了它，知识库、项目管理、功能管理等页面都会以这家公司为范围，新建资源也会挂到它名下。

还没选（未选择）

首次登录 / 刚清过选择时是空的状态。这时很多页面会提示你「先选公司」，按钮也是灰的。

它之所以关键，是因为下面这几个页面的「可用性」直接取决于它有没有被选中：

  • 知识库：没选公司时，列表直接显示 请先在顶部选择公司，新建知识库 也是灰的。
  • 项目管理：没选公司时，顶部挂着一条橙色提示 请先选择或创建一个公司，新建项目 点不动。
  • 公司管理：后面四个页签（组织架构 / 成员管理 / 成员邀请 / 公司设置）全部变灰，只有「公司列表」可看。
  • 设置 → 功能管理：没选公司时提示 请先在顶部选择公司。
换了公司，之前选的「当前项目」会被清掉

你在 A 公司里点进了一个项目，此时「当前选中项目」记着这个项目。如果你在顶栏把公司切换到 B 公司，系统会立刻清空这个记录——因为那个项目根本不属于 B 公司，留着它只会让账本之类的页面显示错乱。所以切完公司以后，如果相关页面变回「公司视角」，是正常行为。记住一句话：换公司等于换上下文，先把公司选对，再进项目。

面包屑：你的「来路」指示牌

内容区顶部有一行小小的导航，形如「首页 / 公司管理 / ……」，用斜杠分隔。第一项永远固定是首页，往后是当前页面所在的路由层级。每一段都可以点，点过去就回到那一层。

有一个小规矩要知道：进入 AI 对话 页时，这行面包屑是不显示的。因为对话页是满屏三栏布局，顶部再塞一行导航会挤。这不是坏了。

授权横幅：如果你看到红条或黄条

在顶栏上方，有时会多出一条横幅，只在授权相关的情况下出现：

颜色 界面原文 含义
红 未激活授权，系统将在 … 后自动关闭 还在试用、没激活。倒计时不足 1 分钟时会显示「即将关闭」，请尽快去「设置 → 授权管理」激活。
黄 网络异常，已按上次激活延期运行至 … 离线宽限：系统暂时连不上授权服务器，按上次激活的状态继续跑一段时间，期间功能不受影响。
看到红条别不当回事

红条不是装饰。倒计时走完，系统会自动关闭。处理方法在「设置 → 授权管理」：把授权码填进 请输入授权码，点 激活。授权码从哪来，问给你开通服务的人。

浏览器的标签页标题也是导航

每切换一个页面，浏览器标签页上的文字会跟着变成「页面名 - ZY 企业智能引擎」。开着好几个标签页时，扫一眼标签就知道哪个是哪个页面。列表页的标题取自各页面自己的名称，比如「数据面板」「公司管理」「项目账本」，超管页面则会在名字后面缀上「（超管）」三个字。

进阶：「进入」和「设置」有什么区别

如果你只是想把顶栏的公司切换器切到某一家，用顶栏那个下拉最快，不必在这一页绕。两者效果一致，改的都是「当前公司」这个上下文。

五、项目管理：进入每个项目的总入口

侧边栏 › 项目管理

这是你使用最频繁的一个页面。它是「公司 → 项目」的最后一跳，也是本章和第 06 章之间的那道门。

页面结构

标题区左边是 项目管理，紧跟一枚小标签显示当前公司名（这样你一眼就知道自己正在哪家公司下建项目）；右边是 新建项目 按钮，它旁边紧跟一个提示。

选了公司

新建项目 亮着，点下去弹出「新建项目向导」，走三步：基本信息 → 预算设定 → 确认提交。每个字段怎么填、填错有什么后果，见第 03 章。

没选公司

页面顶部挂着橙色告警 请先选择或创建一个公司，新建项目 是灰的。项目必须挂在公司下面，所以先去顶栏选一家公司。

项目卡片上有什么

每个项目展示为一张卡片，卡片上能看到：

  • 项目名称——点击进入这个项目。
  • 项目描述——就是建项目时填的那句。没填的话这里显示 暂无描述。
  • 项目类型 / 行业 / 创建时间——用来快速区分不同项目。
  • 连接测试——这是个很实用的小按钮，见下。

如果一个项目都还没有，卡片区显示 暂无项目，点击「新建项目」开始。

「连接测试」按钮：点下去会告诉你三件事

这个按钮用来验证「平台能不能连上这个项目背后的服务器」。它有三种结果，文案各不相同，看懂这三种你就知道问题出在哪一层：

结果 界面提示 说明什么
全通 连接成功：IP:端口，HMAC 验证通过（Nms） 网络能通，签名验证也过了，这台服务器完全正常。括号里是往返耗时，越小越好。
半通 连通但 HMAC 验证失败：错误信息 网络能连到那台机器，但双方密钥对不上。通常是实例密钥不匹配，需要重新核对密钥，不是网络故障。
不通 连接失败：错误信息 连都连不上。可能是服务器没开、地址填错、端口不通。
HMAC 是什么，为什么要测它

HMAC 是一种「带密钥的签名」机制。平台给项目服务器下指令时，会附上一段用密钥算出来的签名；服务器收到后用自己的密钥验一遍，对得上才执行。这样即使有人截获了指令也伪造不了。「连接测试」把网络连通性和签名验证拆开报，就是为了让你一眼分清「是网不通」还是「是密钥不对」。

六、知识库：分层存放你的资料

侧边栏 › 知识库

知识库用来喂给 AI 资料。它的核心概念是分层：公司级的知识放到公司层，所有项目都能用；项目级的知识只归某一个项目；共享知识还能下发给下级。页面标题下面那句 分层知识库（公司级 → 项目级） 点明了这个顺序。

两个页签

「知识库」页签管资料本身，「RAG 检索」页签用来试查。

知识库页签右上角有 新建知识库，同样受公司切换器约束：没选公司时，整个列表显示 请先在顶部选择公司，按钮不可点。列表的列是：名称 / 类型 / 共享 / 文档数 / 分块数 / 状态 / 创建时间 / 操作，操作里有两个文字按钮 文档管理 和 删除。

点 新建知识库 弹出对话框 新建知识库，字段如下：

RAG 检索页签

这个页签的作用是「拿一句话去知识库里试查一下」，看看你的资料有没有被 AI 检索到、相似度多高。

  • 输入框占位符 输入检索关键词，如：产品定位、目标客户、营销策略。
  • 旁边一个条数下拉，可选 Top 5 / 10 / 20。
  • 按钮 检索。
  • 查不到内容时显示 未检索到相关内容。
  • 每条结果上显示 相似度 N%，数字越大表示越相关。
RAG 到底是什么，为什么值得先来这里试一下

RAG 就是「让 AI 先翻你的资料、再回答」。它在回答前会拿你的问题去知识库里找最相关的几段文字，把它们一起交给模型。所以如果你发现 AI「答得不对」，第一步不是怪模型，而是来这个页面试一下：你的问题能不能在这里查出相似度高的结果。查不到，说明是资料没进库或标题不对；查得到但答得还差，才轮到调提问方式。

七、AI 对话：平台级的多轮问答

侧边栏 › AI 对话

这一页是满屏的三栏布局：左边是对话列表，中间是消息区，底部是输入区。顶部没有面包屑（前面讲过，是刻意的）。

三种「空白状态」要分清

新手在这一页最常见的困惑是「怎么空空如也」。其实有三个不同的空，对应三句不同的提示：

左栏没有对话

显示 暂无对话。点 新建对话 就有了。

还没打开任何对话

中间显示 选择或创建一个对话开始，下面配一个 新建对话 按钮。

对话开了但还没说话

消息区显示 开始一个新的对话，外加一行提示：输入消息或上传文件开始与 AI 助手交流。

左栏：对话列表

  • 顶部 新建对话，新建的对话默认叫 新对话。
  • 搜索框占位符 搜索对话...，用来在对话多的时候过滤。
  • 每条对话右侧有下拉菜单，两项：重命名 和 删除。

点重命名会弹出输入框，标题 重命名对话，提示语 请输入新的对话名称，改完提示「已重命名」。点删除会先弹确认框：确定删除这个对话吗？删除后不可恢复。

中间：消息区

对话顶部显示当前对话的名称，右边挂一枚灰色小标签，显示这个对话的归属范围。注意：这个标签显示的是原始英文值（比如 project），不是中文。这是界面上的一个小瑕疵，看到英文别惊讶。

消息分两种：

你发的（右侧）

纯文本。悬停或点按钮有 复制 和 删除。

AI 回的（左侧）

内容更丰富：可能有一段可展开的「思维过程」，可能有一串工具调用卡片，然后是正文。正文下方（且状态已结束、有模型名时）会显示一行小字：模型名、耗时（毫秒 / 秒 / 分钟会自适应）、输出 token 数。操作同样是复制和删除。

工具调用卡片折叠在消息里，展开后能看到两段：参数 和 结果。卡片头部显示工具名和耗时。「思维过程」是模型在给答案前的推理草稿，默认收起，想看它「怎么想的」时可以展开。

AI 正在输出时，删除按钮是点不动的

这是刻意设计——消息还在流式生成时不允许删除，避免删到一半状态错乱。等它输出完，删除按钮就恢复可用了。

删除单条消息的确认文案是 确定删除这条消息吗？删除后不可恢复。

回答失败了？错误会单独成条，不会混进 AI 的话里

如果某次回复没成功（网络中断、上游服务异常等），界面上会出现一个单独的错误块：标题「本次回复未成功完成」，下面一句人话「回复未能完成（可能因网络中断或上游服务异常），请重试；若反复出现，请检查网络或查看实例状态。」。它不会再伪装成 AI 说的一段话，所以你不会把报错当成 AI 的回答。

错误块下方还有一个可折叠的「技术详情」，展开能看到底层返回的原始报错。这主要是给排障用的——日常你按上面那句话重试、或去实例状态看看就行，不必读懂那段英文。

底部：输入区

输入框占位符 输入消息... (Enter 发送, Shift+Enter 换行)。这条提示很实用：回车发送，想换行就按住 Shift 再回车。

输入框旁边有附件入口，支持的文件类型很长一串：.doc / .docx / .pdf / .txt / .md / .xlsx / .xls / .ppt / .pptx / .html / .csv / .json。上传后附件上会显示状态：已解析 / 解析中... / 解析失败。上传成功会提示「已上传: 文件名」。

AI 正在流式输出时，发送区会变成一个红色的 停止 按钮，点它可以打断这次生成。

这里的对话是「平台级」的

平台级的 AI 对话和项目里那套「AI 问答」（在项目内，见第 06 章）不是同一件事。平台级对话走平台自己的通道，除非你把对话显式挂到某个项目上，否则它不会去调那个项目的服务器、也不消耗那个项目的预算与知识库。日常「问点什么」用它，「围绕项目干活」用项目内的 AI 问答。

八、公司账本：真金白银的流水

侧边栏 › 公司账本

菜单里叫「公司账本」，副标题一句把人话讲透了：平台账户真实资金流水：充值、AI 算力费、云服务器费等。这一页管的是你真正充进去的钱。

「公司账本」和「项目账本」是两个账，别搞混

产品里有两条完全不同的账：公司账本（这一页，/ledger）记的是平台账户的真实资金：你充了多少、花了多少、余额还有多少；项目账本（/project/项目号/ledger）记的是某一条业务线的虚拟核算：收入、支出、预算消耗。两者用的是同一个页面组件，靠网址里有没有项目号来决定显示哪一种。所以你会发现「从项目里点项目账本」和「从侧边栏点公司账本」长得像但内容不同——这是设计如此。项目账本那半边的细节（含「账本明细 / 智能看板」两个页签）在第 06 章。

公司账本里的「Token 费 / AI 算力费」现在会真的记账了

公司账本里有一个消费分类叫「Token 费」，指 AI 调用模型花的钱。这一批改动之后，项目里 AI 消耗的 token 会由项目侧按批上报给平台，计入公司账本的真实流水：平台按每批的 report_id 幂等去重，同一批不会重复扣费；上报成功才记账，失败会退避重试、不丢单；上报水位也落了库，进程重启不会重扫历史账。

页面上有一行常显说明写得很清楚：「AI 算力费由项目侧 token 计费批量上报（未开启该上报时不含此项，可在项目账本查看 AI 运行消耗）」。也就是说，只有部署时配好了上报地址的实例，公司账本才会有这项；没配上报地址的实例，公司账本里不含 AI 算力费——这是「未启用」而非「算漏了」。所以做对账前，先看这一行说明：确认上报已开启，再拿公司账本的 Token 费和项目内计费明细对照；没有开启时，AI 消耗请以项目账本的「计费明细 / 运行轮次」为准。

高级功能 营销自动化、战略规划、渐进式信任、冲突仲裁、资源治理、营销引擎、社交媒体运营

第三张卡「AI 智能建议」有点意思：说明写着 AI 根据项目当前状态和经营需求，分析应开启哪些高级功能。，点 分析项目并建议 按钮，AI 会给出一组建议，每条带一个优先级标签（高 / 中 / 低），后面跟一个 开启 按钮，或者一枚灰色的 暂不需要 标签。没有可建议的会显示 暂无建议，所有功能已根据项目状态合理配置。

「安全底线」项真的锁住了，关不掉

手册别处会提「资源治理、预算熔断、渐进式信任属于安全底线」。在当前版本里，这事已经落到界面和后端两层：凡是带「安全底线」小标签的开关（当前是「渐进式信任」和「资源治理」两项），开关是置灰、点不动的，鼠标悬停会提示「该功能为安全底线，不允许关闭」；就算绕过界面直接调接口，后端也会拒绝，并返回「「XX」为安全底线功能，不允许关闭」。换句话说，这几项你想关也关不掉——只能保持开启。

其余开关则可以自由开 / 关。另外项目内的「组织进化 → 定量调控」里还有一套强制维度（预算、自主权限），那是另一处的安全底线，同样不可关。相关背景见第 04 章和第 08 章。

这个开关现在真的「管事」，不只是个显示标记

早前版本里，有些开关拨了好像没反应。现在以下 6 个开关已经真正生效：自动构建部署（deploy）、自动报告（report）、智能报告（auto_report）、营销自动化（marketing）、战略规划（strategy）、渐进式信任（trust_model）。一旦你把某个关掉，再访问对应功能（点按钮、开页面、调接口），系统会直接拒绝并给出中文提示，格式是「XX功能未启用，请在功能开关中开启 KEY」。举几个实际会撞到的例子：

  • 关了 deploy，去点「自动构建部署」，会提示「自动构建部署功能未启用，请在功能开关中开启 deploy」。
  • 关了 strategy，进「战略」页会提示「战略规划功能未启用，请在功能开关中开启 strategy」。
  • 关了 report，看报告配置 / 历史会提示「报告配置功能未启用…」；关了 auto_report，让系统自动生成并推送日报，会提示「智能报告功能未启用…」。

另外，「冲突仲裁、营销引擎、社交媒体、项目模板」这几个开关本来就在生效；只有「通知中心（notification）」这一个目前还没有接上开关门控——这是已知的未完成项，关掉它暂时不影响通知投递。

几个状态提示要知道：没选公司时显示 请先在顶部选择公司；选了公司但公司下还没有项目时，显示 请先选择一个项目以管理其功能开关；选好了项目，卡片上方会显示一行「当前配置：项目名」，提醒你别改错了项目。如果项目列表或开关本身加载失败，页面会分别弹出一条红色提示「项目列表加载失败」或「功能开关加载失败」，带上具体原因，并给一个 重试 链接——不会再静默地显示一个空列表。真的一个开关都没有（不是加载失败）时，显示「该项目暂无功能开关，可点击「重置为默认」初始化」。

进阶：功能开关的 13 个 key 与切换规则

每个功能在接口层有一个英文 key，界面显示的中文名、分组、是否「安全底线」，都以项目服务器下发的字典为唯一来源（前端只做兜底）。对照如下（想查接口文档或排查问题时用得上）：

  • deploy —— 自动构建部署 已生效
  • notification —— 通知中心（尚未门控）
  • backup —— 自动备份
  • report —— 自动报告 已生效
  • marketing —— 营销自动化 已生效
  • strategy —— 战略规划 已生效
  • trust_model —— 渐进式信任 已生效（安全底线，不可关）
  • arbitrator —— 冲突仲裁
  • resource_governor —— 资源治理（安全底线，不可关）
  • marketing_engine —— 营销引擎（后端名为「营销自动化引擎」）
  • social_media —— 社交媒体运营（后端名为「社交媒体管理」）
  • auto_report —— 智能报告 已生效（与上面的「自动报告 report」是两个 key，别混）
  • project_template —— 项目模板

两个容易踩的点：其一，「自动报告（report）」和「智能报告（auto_report）」是两项不同的功能——前者管报告配置与历史阅读，后者管报告的自动生成与推送，界面上已经分开显示，看到两个「报告」别以为重复了。其二，分组与显示名当前统一由后端字典决定：界面按后端下发的分组动态渲染；后端若新增了界面不认识的 key，会归到「其它」分组里，而不是裸奔一个英文 key。所以遇到「功能明明开了、页面说没启用」时，先来这里核对 key 有没有开关到位。

还有个小细节：点 重置为默认 会先弹确认框「将把该项目所有功能开关恢复为默认值，是否继续？」，确认后才执行，成功提示「功能开关已重置为默认值」——这是个破坏性操作，别手滑。

Agent 优化：让系统自己优化智能体

这一页管两件事：常规优化（到一定运行次数后自动优化某个 Agent / 技能）和深度全局优化（定时或手动，把整个项目的执行数据统计一遍再优化）。

常规优化 (Regular) 卡：说明写着「对新创建的 Agent/Skill 达到里程碑次数后自动触发优化分析。」字段有「运行次数里程碑」（默认是 3 / 10 / 40 / 200 这几个数，可以加可以删）、「自定义优化提示词」（占位符「留空使用默认模板」）、「自动应用建议」（旁边注明只自动应用非破坏性的建议，比如提示词调整）。

深度全局优化 (Deep Global) 卡字段更多：

字段 说明
定时执行 (Cron)占位符 如: 0 2 * * 0 (每周日凌晨2:00)，提示「留空则仅支持手动触发」
优化深度三选一：浅度 / 标准 / 深度，默认「标准」。分别对应近 30 天快速分析、近 90 天全面分析、近 180 天深度分析

自动应用建议同常规优化

  • 脱敏：屏幕和导出用同一套口径——手机号中间四位打码（138****8888）、邮箱 @ 前只留一两位（ab***@x.com）。也就是导出的 CSV 里也是脱敏后的内容，不再出现「屏幕脱敏、导出原文」的漏洞。屏幕上还会对你搜的关键词做高亮。
  • 防公式注入：以 =、+、-、@ 开头的文本会被加一个前导单引号，避免用 Excel / WPS 打开时被当成公式执行。

即便如此，导出的内容仍可能含项目内部信息，请按敏感数据管理，别随手外发。

哪些错误会把你踢回登录页，哪些不会

只有「登录态本身失效」这一类（未认证、Token 无效、Token 过期）才会自动跳登录页，并且会记住你原本要去哪，登录后送你回去。而像「登录失败」「该用户名已存在」「账号被封禁」这类，是在当前页面原地显示错误，不会把你踢走。所以如果你改了密码后在别处登录、这边被踢回登录页，是正常的。

分页

记录多的列表（公司账本交易明细、Prompt 审计等）底部有分页条，形如「共 N 条 上一页 页码 下一页」。公司账本用的是最简的一种：只显示总条数 + 上页 / 页码 / 下页。

「累计消费」和项目内的花费不是一回事

公司账本记的是真实资金；项目内的「计费明细」记的是这个项目虚拟核算的花销。两者口径不同，不要交叉相减。AI token 消耗现在会由项目侧批量上报进公司账本（见第八节的提醒），但前提是部署时配好了上报地址——没配的实例，公司账本不含 AI 算力费，这一点账本页也有常显说明。做经营分析仍以项目账本的「计费明细」为准，做资金核对以公司账本为准。

媒体生成的钱

任务记录里的「金额(元)」由服务端按「档位单价 × 用量」折算，计入项目账本。如果你没给某个档位设置单价，那条记录会显示 待定价，金额不折算——这不是系统算错了，而是「宁可空着也不编一个数」。想让它有数，去「价目设置」填上单价。

超管后台的统计

Token 统计页的两种维度讲清楚：累计 Token 数是消耗掉的 token 总量，Token 类消费总额是这些 token 折算成的钱。它还能切换「按模型 / 按用户 / 按项目」看 Top N 排行——用来回答「谁在烧」「哪个模型贵」这类问题。全局看板里的「预算消耗速率」是一个趋势指标，表示当前花钱的速度，比单看「花了多少」更能提前发现问题。

一个小小的对账习惯

养成每周扫一眼「通知中心（预算预警类）」+「公司账本（余额与累计消费）」的习惯。这两个地方是最早能发现「钱不对劲」的位置，比等盯项目内的计费明细更提前。
